# 💬 Java Real-Time Chat Messenger

A simple **client-server chat application** developed using **Java Socket Programming**.  
It allows a client and server to exchange messages in real time through TCP communication.

## 🚀 Features

- Real-time client-server messaging
- TCP/IP communication
- Socket Programming
- Terminal-based chat
- Simple connection management
- Communication using port `2100`

## 🛠️ Technologies Used

- Java
- Socket Programming
- TCP/IP
- Java I/O Streams
- `Socket`
- `ServerSocket`

▶️ How to Run

1. Compile the files
javac ChatServer.java ChatClient.java

2. Start the Server

Open the first terminal:
java ChatServer
The server will wait for a client connection on port 2100.

3. Start the Client

Open a second terminal:
java ChatClient
The client will connect to the server and allow message exchange.

4. End the Chat

Enter:
end
to close the client connection.
